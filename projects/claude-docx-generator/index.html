// The Problem You Got the Code. Where's the Document?

You ask an AI assistant to help build a 40-page report, a proposal, a thesis draft, or a technical document. It happily writes out everything needed to produce your Word file — sometimes hundreds of lines of it. Then the conversation ends, and there's no file. Just code sitting there, useless to anyone who needs pages they can actually open.

And it usually fails in one of three familiar ways. The session times out before the actual file is ever produced. Or the code points to a folder on the AI's machine — something like /mnt/data/report.docx — that simply doesn't exist on yours. Or the code came from Claude, ChatGPT, Gemini, or another chat platform that saved its files somewhere you can't reach from your own computer.

So you're left doing chores: copying the code, hunting down every file location, fixing, re-running, fixing again. All you wanted was the document — now.

// How It Works From Dead-End Code to Done in Four Steps

Install It Once

One short command adds the tool to your computer. No account, no cloud — it lives with you.

Paste the AI's Code

Drop the code your AI produced into paste_here.js — the one file created exactly for this. Don't change a character.

Run a Single Command

Type the run command, press enter, and give it a moment to do its thing.

Collect Your Document

A real Word file appears in your outputs folder. Open it, attach it, submit it — done.

npm install claude-docx-generator node paste_here.js npm run paste npx claude-docx-generator
