CampusVote E-Voting Suite

A two-campus student election concept for Kihumuro and Town Campus. This hub groups the three prototype demos in one place so the project stays easy to explore.

Project Summary

CampusVote is a civic-tech prototype for student elections. The current demos focus on visual turnout insight, live race tracking, and a ballot flow that makes the voting experience easier to understand.

Django PostgreSQL HTML/CSS
