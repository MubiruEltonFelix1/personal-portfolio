// The Problem Everyone Uses AI. Almost No One Can Explain It.

Today, anyone can copy ten lines of someone else's code and call themselves an AI builder. It feels like knowledge — right up until a recruiter, an interviewer, or your own curiosity asks one simple question: "but how does it actually learn?" And the honest answer is silence.

Most tutorials only show you which buttons to press. They never open the machine: why a network improves, why it suddenly gets worse, or what all the numbers inside are really doing. You end up driving a car you couldn't draw from memory — powerful, until something breaks or someone asks you to prove you know what's under the hood.

TinyCNN started from that exact discomfort. If I couldn't explain it, I didn't truly know it. So instead of leaning on ready-made tools, I set out to build the machine myself — from nothing but mathematics, one piece at a time.

// How It Works How a Network Actually Learns

Take a Guess

Information flows forward through layers that were written by hand, each one reshaping it until the network produces an answer.

Measure the Miss

That answer is compared against the truth, and the size of the mistake is boiled down into one clear score.

Blame, Then Adjust

The score travels backwards through the network, and every number inside learns exactly how much it contributed to the error — and which way to move.

Repeat Until Skilful

Run this loop over and over and tiny corrections stack up: wild guesses slowly turn into reliable predictions you can watch happen live.
