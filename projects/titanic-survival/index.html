Titanic Dataset Analysis & Survival Prediction

Project Description

Comprehensive machine learning analysis of the famous Titanic dataset to predict passenger survival rates. Built a complete ML pipeline with extensive feature engineering, data preprocessing, and exploratory data analysis.

Implemented multiple algorithms including Random Forest, Logistic Regression, and SVM to achieve 84.5% prediction accuracy with detailed visualizations and model comparison.
