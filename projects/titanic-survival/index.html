Walter Bishop Labs: Calculus Experiments

Project Description

Walter Bishop Labs Calculus is a computational mathematics project that treats calculus concepts as systems to model, differentiate, visualize, and extend through code.

The repository follows an experiment-first architecture. The current implementation analyzes function behavior using symbolic derivatives, critical point logic, numerical sampling, and visual reporting.

PythonSymPyNumPyMatplotlibCalculusScientific Computing
GitHub Repository

Challenges & Solutions

Challenge: translating abstract calculus ideas into clear computational workflows. Solution: combine symbolic exactness with numerical simulation and visual interpretation so each experiment explains both what happens and why it happens.

Quick Start

Install dependencies from requirements.txt, then run the first experiment:

pip install -r requirements.txt
cd experiments/experiment_01_function_behavior_analysis
python main.py
