What is BrainBolt?

BrainBolt is an esports-broadcast styled, real-time quiz arena where hosts run live trivia battles and players join from any device using a short room code. Built for classrooms, team offsites, Twitch streams, and competitive league seasons, BrainBolt blends Kahoot-style energy with persistent team and league structures.

Whether you're hosting a one-off pub quiz or running an ongoing trivia league across multiple teams, BrainBolt gives you the tooling to author, host, play, and rank — all in real time.

Core Features

Quiz Engine

Create unlimited quizzes with multiple-choice questions. Per-question time limits, point values, and correct-answer flags. Inline editing, drag-free reordering, and CSV bulk import.

Real-Time Hosting

Live host dashboard to control flow, reveal answers, advance questions. Auto-advance mode and player presence tracking with short join codes.

Player Experience

Live rank indicator updating in real time. Hidden leaderboard until the final question. Mobile-first tap-to-answer. Guest play with no account required.

Teams & Leagues

Create and manage teams with persistent rosters. Team-based scoring, role-aware permissions. Season structures grouping multiple quizzes into a league with cumulative standings.

Design System

Esports broadcast aesthetic with volt yellow, neon teal, and pink-shock accents. Skewed CTAs, Anton + JetBrains Mono + Inter pairing. Dark-mode native with semantic CSS variables.

Auth & Security

Email + Google OAuth via Lovable Cloud. Row-Level Security on every table. Role-based permissions via a dedicated user_roles table with auth-gated routes.

How It Works

1

Create or import a quiz

Author questions with the built-in editor or bulk import via CSV with flexible header matching.

2

Host a live session

Players join with a short room code from any device. Control question flow from the live dashboard.

3

Play in real time

Scores update live as answers roll in. Players see their rank changing in real time.

4

Review & rank

Full leaderboard revealed after the final question. League standings accumulate across multiple sessions.
