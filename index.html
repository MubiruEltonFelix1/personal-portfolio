Titanic Dataset Analysis & Survival Prediction

Comprehensive machine learning analysis of the famous Titanic dataset to predict passenger survival rates. Built a complete ML pipeline with extensive feature engineering, data preprocessing, and exploratory data analysis. Implemented multiple algorithms including Random Forest, Logistic Regression, and SVM to achieve 84.5% prediction accuracy. The project includes detailed visualizations, statistical insights, and model comparison analysis to understand the key factors that influenced passenger survival during the tragic maritime disaster.
