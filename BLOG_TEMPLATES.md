# Blog Post Templates

Quick copy-paste templates for adding new blog posts to your blog.html file.

## 📝 Standard Blog Post Template

```html
<article class="blog-post" data-category="CATEGORY_HERE">
  <div class="post-image">
    <div class="post-image-placeholder">
      <i class="fas fa-ICON_HERE"></i>
    </div>
    <!-- Optional badge -->
    <div class="post-badge">New</div>
  </div>
  <div class="post-content">
    <div class="post-meta">
      <span class="post-category">CATEGORY_DISPLAY_NAME</span>
      <span class="post-date">Month Day, Year</span>
    </div>
    <h3 class="post-title">Your Compelling Blog Post Title Here</h3>
    <p class="post-excerpt">
      Write a compelling 100-150 character excerpt that makes people want to click "Read More".
      Focus on the benefit or value to the reader.
    </p>
    <div class="post-tags">
      <span class="tag">tag1</span>
      <span class="tag">tag2</span>
      <span class="tag">tag3</span>
    </div>
    <a href="#" class="read-more-btn">
      Read More
      <i class="fas fa-arrow-right"></i>
    </a>
  </div>
</article>
```

## ⚡ Quick Steps to Add a Post

1. **Copy** one of the templates above
2. **Paste** it in `blog.html` before the "Coming Soon" notice (around line 270)
3. **Update** the category, icon, title, date, excerpt, and tags
4. **Add full content** in `blog.js` using the `getBlogPostContent` function
5. **Save** both files
6. **Test** the category filtering and "Read More" functionality
7. **Commit** your changes to Git

## 📝 Adding Full Blog Post Content

After adding the blog card to `blog.html`, you need to add the full content to `blog.js`:

### Template for Full Content

```javascript
"Your Exact Blog Post Title": {
    content: `
        <p>Start with an engaging introduction that hooks the reader and explains what they'll learn.</p>

        <h2>Main Section 1</h2>
        <p>Break your content into digestible sections with clear headings.</p>

        <h3>Subsection</h3>
        <p>Use subsections when you need to dive deeper into a topic.</p>

        <ul>
            <li>Use bullet points for lists</li>
            <li>Make them scannable and actionable</li>
            <li>Each point should be valuable</li>
        </ul>

        <blockquote>"Include inspiring quotes or key insights to break up the text."</blockquote>

        <h2>Main Section 2</h2>
        <p>Continue with your next major point or section.</p>

        <h3>Code Examples (if relevant)</h3>
        <p>When writing technical posts, include code examples:</p>
        <pre><code>
function example() {
    return "This is how you format code blocks";
}
        </code></pre>

        <p>Or use inline code like <code>variable names</code> or <code>function()</code> calls.</p>

        <h2>Conclusion</h2>
        <p>End with a summary of key takeaways and encourage engagement.</p>
    `
},
```

### Content Writing Best Practices

1. **Match the title exactly** - The title in `blog.js` must match the HTML exactly
2. **Use proper HTML structure** - Headings, paragraphs, lists, etc.
3. **Include code formatting** - Use `<code>` and `<pre><code>` for code
4. **Add blockquotes** - Great for highlighting key insights
5. **Keep it scannable** - Use headings and lists to break up text

## 🔍 Where to Insert New Posts

In `blog.html`, find this section and add your new post above it:

```html
<!-- Coming Soon Notice -->
<div class="coming-soon-notice">
  <!-- ADD NEW POSTS ABOVE THIS LINE -->
</div>
```

The exact line number is around **line 270-280** in `blog.html`.
