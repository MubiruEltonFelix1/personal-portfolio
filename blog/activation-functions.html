Activation Functions — ReLU, Sigmoid & Friends

6 min read Beginner

Without activation functions, a neural network — no matter how deep — would be equivalent to a single linear transformation. All those layers would collapse into one matrix multiplication. Activation functions are what give neural networks their nonlinearity — their ability to learn complex, curved decision boundaries instead of just straight lines.

Why Nonlinearity Matters

Imagine trying to separate two classes of points arranged in concentric circles using only straight lines. Impossible, right? You need curves. Activation functions are what let neural networks draw those curves. Without them, the network can only learn linear relationships — and most real-world problems are highly nonlinear.

The Contenders

ReLU — Rectified Linear Unit

f(x) = max(0, x)

If the input is positive, pass it through unchanged. If negative, output zero. That's it. ReLU is dead simple, computationally cheap, and — critically — doesn't saturate for positive values, which prevents the vanishing gradient problem in deep networks.

When to use: Your default choice for hidden layers in feed-forward and convolutional networks. Start here.

Watch out for: "Dying ReLU" — if a neuron's weights push it into always-outputting-zero territory, its gradient is zero and it stops learning permanently. Leaky ReLU (f(x) = max(0.01x, x)) and ELU fix this with a small negative slope.

Sigmoid

f(x) = 1 / (1 + e^(-x))

The classic S-curve that squashes any input into the range (0, 1). Historically popular because it has a nice probabilistic interpretation — the output can be read as a probability.

When to use: The output layer of binary classification problems (e.g., "is this email spam?"). For hidden layers, ReLU has largely replaced it.

Watch out for: Saturates for large positive or negative inputs — the gradient becomes nearly zero, causing vanishing gradients in deep networks. Also, outputs are not zero-centered, which can cause zigzagging during optimization.

Tanh

f(x) = (e^x - e^(-x)) / (e^x + e^(-x))

Like sigmoid but stretched to output in (-1, 1) and zero-centered. Historically preferred over sigmoid for hidden layers because zero-centered outputs help gradient descent converge faster.

When to use: Sometimes in recurrent neural networks (RNNs, LSTMs). For feed-forward hidden layers, ReLU variants are generally better.

Watch out for: Same saturation problem as sigmoid — gradients vanish for inputs far from zero.

Softmax

Not quite an activation function in the traditional sense — it's used exclusively in the output layer for multi-class classification. It converts a vector of raw scores into a probability distribution (all outputs between 0 and 1, summing to 1).

When to use: Output layer for classification with 3+ classes.

Quick Decision Guide

  • Hidden layers (feed-forward / CNN): ReLU. If dying neurons become a problem, try Leaky ReLU or ELU.
  • Binary classification output: Sigmoid (1 neuron) with binary cross-entropy loss.
  • Multi-class classification output: Softmax with categorical cross-entropy loss.
  • Regression output: No activation (linear) — let the network output any real number.
  • RNN / LSTM gates: Sigmoid (for gating) and Tanh (for state updates).
"Start with ReLU. The others are solutions to problems you probably don't have yet."

Activation functions aren't a place to overthink early on. ReLU works for 90% of cases. When it doesn't, you'll know — your loss will plateau, your gradients will vanish, and then you can reach for the alternatives with a clear understanding of why.
