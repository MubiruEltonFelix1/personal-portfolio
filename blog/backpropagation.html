How Backpropagation Actually Works

8 min read Intermediate

If gradient descent is the engine of deep learning, backpropagation is the fuel injection system. It's the algorithm that figures out exactly how much each of the millions (or billions) of parameters in a neural network should be adjusted to reduce the error. Without it, training deep networks would be computationally impossible.

The Problem: Who's to Blame?

Imagine a neural network with 5 layers, each with 100 neurons. That's tens of thousands of weights. When the network makes a wrong prediction, every single weight contributed to that error — some more than others. But how do we figure out which weights need the biggest adjustment?

We could try changing each weight slightly and measuring the effect. But with thousands of weights and thousands of training examples, that would take forever. Backpropagation solves this by computing all the necessary adjustments in one forward pass and one backward pass.

The Chain Rule: The Mathematical Trick

Backpropagation is, at its core, an efficient application of the chain rule from calculus. If you have a chain of functions — like a neural network where each layer's output feeds into the next — the chain rule lets you compute how a change at the beginning propagates all the way to the end.

Concretely: the loss depends on the output. The output depends on the last hidden layer. That layer depends on the one before it. And so on, back to the input. The chain rule says: multiply the derivatives along the chain to get the total effect of changing an early weight on the final loss.

"Backpropagation is just the chain rule applied repeatedly from the output layer backward to the input layer."

The Two Phases

Phase 1: Forward Pass

Feed an input through the network, layer by layer. At each neuron, multiply incoming values by weights, sum them up, add bias, and apply the activation function. Store everything — every intermediate value and every activation — because we'll need them in phase 2.

Phase 2: Backward Pass

Start at the output layer. Compute how much the loss changes with respect to the output ("how wrong were we?"). Then work backward, layer by layer:

  1. Compute how much the loss changes with respect to that layer's weights
  2. Compute how much the loss changes with respect to that layer's inputs (to pass to the previous layer)
  3. Update the weights using gradient descent

By the time you reach the input layer, every weight in the network has its gradient computed, and one gradient descent step updates them all simultaneously.

Why "Back" Propagation?

The name comes from the direction: information about the error flows backward through the network, opposite to the forward pass. Early layers learn how to adjust based on feedback from later layers — which makes intuitive sense. If the output is wrong, the last layer is most directly responsible, but its error traces back through earlier layers that fed it bad representations.

Why It's So Efficient

Without backpropagation, computing the gradient for a network with N weights would require roughly N forward passes per training example. Backpropagation does it in one forward + one backward pass, regardless of N. This is what made training deep networks practical when compute became available.

Common Pitfalls

Vanishing Gradients

In very deep networks with certain activation functions (especially sigmoid and tanh), gradients can shrink exponentially as they propagate backward. Early layers receive gradients so tiny they effectively stop learning. This is why ReLU became popular — it doesn't squash gradients in the positive region.

Exploding Gradients

The opposite problem: gradients grow exponentially and weights receive enormous updates, causing the loss to swing wildly or go to infinity. Gradient clipping (capping the maximum gradient value) is a simple fix.

Dead Neurons

With ReLU, if a neuron's weights push it into the negative region for all inputs, its gradient becomes zero and it never recovers. This is why variants like Leaky ReLU exist.

Backpropagation is the quiet workhorse behind every deep learning breakthrough. It's not glamorous, but understanding it gives you a genuine advantage when debugging models or designing architectures.
